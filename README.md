# Client Requirement AI Agent

A simple AI-powered agent that helps gather and summarize a client's website 
project requirements using the Google Gemini API. It takes details like project 
type, budget, and deadline, and generates a clear, structured requirement summary.

## Features
- Takes Project Type, Business Name, Budget, Deadline, and Extra Details as input
- Uses Gemini LLM (gemini-2.0-flash) to generate a structured project summary
- Outputs: Project Overview, Key Features, Suggested Tech Stack, Timeline, and Next Steps

## PEAS Framework

| Component | Description |
|---|---|
| **Performance Measure** | Completeness and clarity of the generated requirement summary |
| **Environment** | Project type, business name, budget, deadline, extra details |
| **Actuators** | Structured requirement summary generated by the Gemini LLM |
| **Sensors** | Client's typed text input |

## How to Run
1. Open this notebook in Google Colab
2. Add your Gemini API key to Colab Secrets with the name `GEMINI_API_KEY`
3. Run all cells from top to bottom (Runtime → Run all)
4. Call the function with your project type, business name, budget, deadline, and details

## Example
```python
result = project_requirement_agent(
    "Shopify Store",
    "22inc.shop",
    "PKR 50,000",
    "3 weeks",
    "Luxury menswear brand, dark/gold theme, need product pages and checkout"
)
print(result)
```
